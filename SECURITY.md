# 🛡️ Security Policy

## Supported Versions

Only the latest version of this repository is actively maintained.

| Version | Supported          |
| ------- | ------------------ |
| latest  | ✅ Yes             |
| < latest | ❌ No              |

## 📣 Reporting a Vulnerability

If you discover a vulnerability or a potential security issue in **Sereni Tunisia**, **do NOT open a public GitHub issue**.  
Instead, please report it privately by emailing:

📧 **ordi2000@hotmail.fr**

We will investigate and respond as quickly as possible. Thank you for helping keep this project secure.

## 🔒 Sensitive Data Notice

This project may contain sensitive or private data related to healthcare and personal wellbeing services.  
Please handle with **strict confidentiality** and avoid redistributing or exposing user-related information without explicit consent.
